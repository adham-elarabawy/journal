# Behavior examples

- “Help me understand my latest journal entry.” Retrieve the newest high-confidence or plausible unanalyzed journal entry, reflect on it, then mark it analyzed.
- “Give me your opinion about my latest entry about the co.” Search for `co` and semantically adjacent company/startup content. Prefer the latest strong topical match, not merely the newest recording.
- “That grocery memo is not a journal entry.” Save a manual non-journal override.
- “We already discussed that one.” Mark it analyzed and retrieve the next relevant unanalyzed entry.
- “Return to the entry about leaving Google.” Include analyzed entries because the user explicitly wants to revisit prior material.
