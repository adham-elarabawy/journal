# Behavior examples

- “Help me understand my latest journal entry.” Retrieve the newest high-confidence or plausible unanalyzed journal entry, reflect on it, then mark it analyzed.
- “Give me your perspective on my latest entry about a difficult decision.” Search for the decision and semantically related content. Prefer the latest strong topical match, not merely the newest recording.
- “That grocery memo is not a journal entry.” Save a manual non-journal override.
- “We already discussed that one.” Mark it analyzed and retrieve the next relevant unanalyzed entry.
- “Return to the entry about changing careers.” Include analyzed entries because the user explicitly wants to revisit prior material.
